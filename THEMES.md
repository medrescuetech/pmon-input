# Additional themes

Bundled from [bullseye555/pagermon_themes](https://github.com/bullseye555/pagermon_themes), source commit `16aa98bf16f161c7d4ffe9783ff9544ea6542687`.

| Theme | Appearance |
| --- | --- |
| `default` | Original PagerMon layout and colours |
| `compact-default` | Compact layout, original colours |
| `dark-mode` | Original layout, dark colours |
| `compact-dark-mode` | Compact layout and dark colours |

In GoDaddy, pull branch `godaddy-pagermon` from GitHub. In PagerMon, choose **Admin → Settings → Theme**, select the theme, save, then restart the preview/application. Publish the updated app when ready. The selected theme is retained in the persistent configuration.

All three additional themes were checked against this port for login, authenticated message and admin pages, CSS, settings template and error-page rendering. Default selection is unchanged by installation.
